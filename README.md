# MINI PROJECT 1
## Implement your very own C-Shell & Implement the MLFQ scheduling policy for xv6

A shell written in C for Operating systems course mini project by Me.

### Run Instructions
1. Navigate to ./c-shell/ directory
2. clean previous builds justincase `make clean2>&1`
3. compile the shell `make all 2>&1 && echo Done`
4. to run Ibrahim's Really Innovative Shell v0.1 (irish): `./shell.out          # ensure you're in /c-shell/ directory first`
5. Hardcoded exit command `exit` for convinience
